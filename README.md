# ToffuLab Apps

Website tĩnh cho GitHub Pages. Nguồn xuất bản là nhánh `main`, thư mục `/` của repo `TofuLab-Apps/TofuLab-Apps.github.io`.

- Trang chính: https://tofulab-apps.github.io/
- HIẾM!: https://tofulab-apps.github.io/games/hiem/
- Chính sách quyền riêng tư: https://tofulab-apps.github.io/games/hiem/privacy/
- Điều khoản: https://tofulab-apps.github.io/games/hiem/terms/
- Hỗ trợ: https://tofulab-apps.github.io/support/
- AdMob: https://tofulab-apps.github.io/app-ads.txt

Trước khi đăng, duyệt nội dung quyền riêng tư theo cấu hình SDK của bản phát hành, tên nhà phát triển trong Play Console và đối chiếu dòng app-ads.txt với dashboard AdMob. Sau khi bật Pages, kiểm tra các URL công khai qua HTTPS. Khi có link Google Play, cập nhật trạng thái và nút tải ở trang HIẾM!.
